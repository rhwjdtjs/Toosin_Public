# TOOSIN : 투신

A single-player arena action roguelike built with Unreal Engine 5.5.

Enemies record combat habits such as attack choices, guard timing and movement, then use those statistics in rule-based decisions. You can combine classes, weapons, combos, Traits and Perks across Stage, Infinite and Ranked modes. Season 2 Ranked battles place one player and four allied AI fighters against five enemy AI fighters.

## Current status

Updated October 1, 2026.

Version 1.0 launched on August 13, 2026 (Korea time). This repository contains public update notes through Version 1.3.1. **Version 1.4 is in preparation**, with Codex and Claude assisting implementation, debugging and documentation.

Current work covers the hub and menu layout, appearance and class selection, combat animations, AI behavior, saving and localization. Development checks cover selected builds, automated tests and runtime captures. Packaging and remaining play checks still need to be completed before these changes can be described as a release.
