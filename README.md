# 투신 (Toosin)

### 1v1 검투사 로그라이크 액션 게임

**🗡️ 적은 당신의 패턴을 학습합니다. 끊임없이 적응하고 강해지십시오.**

> **투신**은 언리얼 엔진 5.5.4로 개발 중인 **1대1 아레나 로그라이크 액션 게임**입니다.
>
> 플레이어는 검투사가 되어 강력한 AI와 목숨을 건 결투를 벌이며, 매 승리마다 무작위 특성 및 특전을 획득하여 자신만의 전투 스타일을 구축합니다.

- **엔진:** Unreal Engine 5.5.4
- **플랫폼:** PC (Steam 예정)
- **출시 목표:** 2026년 4월 30일 이내

## 📖 게임 정보 (About This Game)

기묘한 투기장에서 눈을 뜬 순간, 당신은 끝없는 전투를 치러야 한다는 것을 깨닫게 됩니다.
**당신의 공격 패턴, 회피 방향, 즐겨 쓰는 콤보까지... 적은 모든 것을 기억합니다.**
평범한 능력치와 장비로 시작해 매번 치열한 공방을 거치며, 무작위 특성을 활용해 당신만의 완벽한 콤보를 만들어야 합니다!

<br/>

### ⚔️ 정교하고 치열한 전투 시스템

**패링**으로 적의 공격을 정확한 타이밍에 튕겨내고, 틈을 노려 공격하여 전세를 뒤집으세요! 공격, 가드, 회피 모두 **스태미나 관리**가 필수적입니다. 무지성 공격은 가드 브레이크를 유발하여 치명적인 반격을 맞게 됩니다.

### 🧠 나를 뛰어넘는 적, 자가 학습 AI

이곳의 전사는 단순한 AI가 아닙니다. 당신의 **공격 빈도, 방어 스타일, 콤보 궤적**을 실시간으로 분석합니다. 판수가 거듭될수록 똑같은 패턴은 간파당하고, AI는 점점 더 영악하게 진화합니다. 살아남으려면 끊임없이 변칙적으로 행동하세요.

### 🎲 매 판 새로운 한계 돌파, 로그라이크 성장

라운드 종료 후 주어지는 **무작위 특전**을 선택해 다음 전투를 대비하세요. 전투 사이 휴식처인 '허브'에서 무기를 교체하고 스탯을 분배하며, 상점에서는 무기 타입에 따라 공격 콤보를 구매하고, 총 **100**개의 특성 간의 시너지를 극대화하여 자신만의 전투 스타일을 확립할 수 있습니다.
